# Hollowmere: The Lantern Road (downloads)

This page only holds the finished game and its patch notes. Get the newest version from **[Releases](../../releases/latest)**.

## Installing

- **Windows:** download `Hollowmere-windows.zip`, unzip it and double-click `Hollowmere.exe`. If SmartScreen warns about an unknown app, click **More info**, then **Run anyway**.
- **Linux:** download `Hollowmere-linux.zip`, unzip it (right-click → Extract here), open a terminal in the `Hollowmere` folder and type `sh install.sh`. Hollowmere then appears in your app menu and on your desktop.

Make sure you download the zip under **Assets** on the release, not "Source code".

## Updating

From version 1.1.0 on, the game updates itself: on the title screen, click **Update** when it glows, then **Download and install** and **Restart now**. Your saves are never touched.

## Playing together

Everyone must be on the same version. One player clicks **Multiplayer → Host a game**, everyone else types the host's address and clicks **Join**.
